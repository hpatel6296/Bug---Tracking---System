-> Bug Tracking System 

== System Features
   - User Authentication Role : Secure login and registration engine supporting role-based access control (Admin, Developer, and Testerpermissions).
   - Ticket CRUD Operation :Full lifecycle management allowing authorized users to create, view, edit, reassign, and delete bug reports.
   - Severity & Priority Tagging Categorization options (Low, Medium, High, Critical) to prioritize resolution workflows efficiently.
   - Database Persistence Relational database integration ensuring real-time state persistence for active and closed bug tickets.

  == System WorkFlows
     - Authentication & Role Verification
     - Bug Submission
     - Triage & developer Assignment
     - Resolution and Patch Submission
     - Verification and Ticket Closuer

  == User Interface Architecture 
    - Login & Registration Page : From inputs for user credentials with client-side and server-side validation.
    - Main Dashboard: Overview panel displaying active bugs, ticket status counters, and priority highlights.
    - Bug Reporting Interface: Clean form layout with standard input fields for title, category dropdowns, and text descriptions.
    - Ticket Detailed View: Comprehensive page displaying complete history, assigned engineer, current status, and action buttons.
